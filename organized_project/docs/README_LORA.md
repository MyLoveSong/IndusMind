# LoRA训练代码和结果

## 文件说明

### 训练脚本
- `train_lora.py` - 主要的LoRA训练脚本，支持分布式训练和实时监控
- `run_full_train.sh` - 训练启动脚本，使用Accelerate进行4GPU分布式训练
- `deepspeed_config.json` - DeepSpeed配置文件，配置ZeRO-2优化和BF16精度

### 评估脚本
- `evaluate_and_export.py` - 模型评估和推理脚本

### 评估结果文件
- `eval_report.html` - 详细的评估报告，包含性能指标和样本输出
- `cosine_hist.png` - 余弦相似度分布直方图
- `metrics_bar.png` - 评估指标柱状图

### 训练趋势可视化 (英文标签)
- `training_trends_*.png` - 完整的训练趋势分析图（包含Loss曲线、学习率、梯度范数、Loss分布）
- `loss_curve_*.png` - 单独的Loss曲线图
- `plot_training_trends.py` - 训练趋势分析脚本（已更新为英文标签）

## 训练配置

- **模型**: Qwen-8B
- **LoRA配置**: rank=8, alpha=16, dropout=0.1
- **训练设置**: BF16精度，分布式训练，梯度累积
- **数据集**: 白皮书文本数据（JSONL格式）

## 使用方法

1. 安装依赖：
```bash
pip install torch transformers accelerate peft datasets
```

2. 启动训练：
```bash
bash run_full_train.sh
```

3. 评估模型：
```bash
python evaluate_and_export.py
```

4. 生成训练趋势图：
```bash
python plot_training_trends.py
```
